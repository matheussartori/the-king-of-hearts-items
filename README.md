# The King of Hearts — item pictures

The pictures of the Steam inventory items of [The King of Hearts](https://store.steampowered.com/app/5442680/), served by
GitHub Pages for the Inventory Service schema (`icon_url`, `icon_url_large`). Written by the item card script in the art
repository; one folder per version, since Steam caches a picture by its URL (v1 was never filled).
